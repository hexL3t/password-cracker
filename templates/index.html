The Password Cracker web tool allows users to input a password, which is then cracked using a brute-force technique. The web tool provides real-time progress updates, showing the cracked password character by character and the time taken to crack it.

    how it works:

    • Enter a password and hit "Crack Password."
    • The tool will attempt to match each character from a predefined dictionary, showing progress as it goes.
    • The process time is displayed at the end, indicating how long the cracking process took.
    • Elapsed Time: Displays how long the cracking process takes.
    • You can reset the progress using the "Clear Progress" button.
